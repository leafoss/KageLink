Os links sempre apontam para a **versão estável mais recente**. O KageLink 3.5.0 inclui o Dojo Trainer no Setup Windows e seus controles remotos no APK.

### Instalação

**Windows**

1. Baixe `KageLink-Windows-Setup.exe`.
2. Feche qualquer KageLink antigo.
3. Execute o instalador.
4. Abra o KageLink pelo atalho ou Menu Iniciar.
5. Escolha PT-BR ou EN-US e mantenha a porta padrão `8765`, salvo necessidade específica.

O Setup instala automaticamente:

```text
KageLink.exe
KagePilotDojo.exe
KagePilotRound.exe
```

Os helpers do Dojo ficam no mesmo diretório do KageLink e não exigem Python instalado. Não mova nem execute esses arquivos separadamente.

**Android**

1. Baixe `KageLink-Android.apk`.
2. Abra e instale o APK.
3. Copie do PC o endereço e a chave de acesso.
4. Crie uma conexão no aplicativo.
5. Use a área **Dojo** para iniciar, parar e acompanhar o treino executado no Windows.

O APK é uma interface remota: visão, decisões e teclado continuam executando somente no PC Agent.

## English

### Quick download

| Windows | Android |
| --- | --- |
| **[⬇ Download Windows installer](https://github.com/leafoss/KageLink/releases/latest/download/KageLink-Windows-Setup.exe)** | **[⬇ Download Android APK](https://github.com/leafoss/KageLink/releases/latest/download/KageLink-Android.apk)** |

The links always point to the **latest stable release**. KageLink 3.5.0 includes Dojo Trainer in the Windows Setup and remote controls in the APK.

### Installation

**Windows**

1. Download `KageLink-Windows-Setup.exe`.
2. Close any older KageLink instance.
3. Run the installer.
4. Open KageLink from the shortcut or Start Menu.
5. Choose PT-BR or EN-US and keep the default port `8765` unless another port is required.

The Setup automatically installs:

```text
KageLink.exe
KagePilotDojo.exe
KagePilotRound.exe
```

The Dojo helpers stay beside KageLink and require no installed Python. Do not move or execute them separately.

**Android**

1. Download `KageLink-Android.apk`.
2. Open and install the APK.
3. Copy the address and access key from the PC.
4. Create a connection in the app.
5. Use the **Dojo** area to start, stop, and follow training running on Windows.

Android is a remote interface: vision, decisions, and keyboard input continue to run only in the PC Agent.

### Verify the download

The same Release includes `SHA256SUMS.txt` with the SHA-256 hashes of both official files.
